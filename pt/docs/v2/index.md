## 💡 O Que Há de Novo em v2.0?

v2.0.0 traz melhorias significativas mantendo a simplicidade que você ama:

- **🏗️ Arquitetura Reimaginada**: Estrutura melhorada para projetos maiores
- **⚡ Performance Aprimorada**: Otimizações em cache e execução
- **📦 Novos Recursos**: Extensibilidade enhancida e novos padrões
- **🔧 API Melhorada**: Interfaces mais intuitivas e consistentes
- **📚 Documentação Expandida**: Cobertura completa dos novos recursos

---

## 🎯 Migração de v1.2.0

Se você está usando v1.2.0 e quer experimentar v2.0 beta:

```bash
composer require pivotphp/core:^2.0@beta
```

**Nota**: Alterações podem ocorrer durante o desenvolvimento beta. Veja o [Guia de Migração]({{ '/pt/docs/v2/migration/' | relative_url }}) para mais detalhes.

## 🌟 Recursos Principais

Todos os recursos de v1.2.0, mais:

### 🏗️ Melhorias Arquiteturais

- Sistema de plugins expandido
- Melhor suporte a middleware assíncrono
- Estrutura de diretórios aprimorada

### ⚡ Performance

- Cache inteligente por padrão
- Compilação otimizada de rotas
- Redução de overhead em middleware

### 📦 Novos Recursos

- Novos tipos de eventos
- Sistema de hooks melhorado
- Melhor integração com extensões
